# Cars Dealership – Full Stack Application Development Capstone

## Project Overview

Cars Dealership is a full-stack web application developed for the IBM Full Stack Application Development Capstone Project on Coursera.

Users can browse dealerships, filter by state, view dealership details and customer reviews, register, log in, and submit dealership reviews.

## Key Features

- Browse all dealerships
- Filter dealerships by state
- View dealership details and reviews
- Register, log in, and log out
- Submit reviews as an authenticated user
- Select car makes and models

## Technology Stack

- Frontend: React.js
- Backend: Django and Python
- REST API: Node.js and Express.js
- Database: MongoDB Atlas and SQLite
- Deployment: Render
- Version Control: Git and GitHub

## REST API Endpoints

- GET /fetchDealers
- GET /fetchDealers/:state
- GET /fetchDealer/:id
- GET /fetchReviews/dealer/:id
- POST /insert_review
